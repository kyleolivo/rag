# condo-rag

A RAG system over the documents of a single condo building (bylaws, rules &
regs, insurance, financials, board meeting minutes). Retrieval & ranking is
the area of greatest depth.

- [`DESIGN.md`](./DESIGN.md) — requirements, architecture, data model,
  trade-offs.
- [`ROADMAP.md`](./ROADMAP.md) — bite-sized chunks of work in build order
  (ingestion → retrieval → generation → eval → serving). Pick one per
  session.
